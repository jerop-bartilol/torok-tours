# Torok Tours & Travel Ltd

A modern, digitally-enabled tours and travel website built with Next.js, TypeScript, and Tailwind CSS.

## About Torok Tours & Travel Ltd

Torok Tours & Travel Ltd operates in the tours and travel industry, serving a diverse clientele including tourists, corporate organizations, NGOs, and group travel clients. The company is built on a strong foundation of reliability, comfort, and customer satisfaction.

This project is part of a broader digital transformation initiative in collaboration with KibandaLabs Technologies — designed to elevate Torok into a modern, highly visible brand supported by strong systems, professional branding, and strategic marketing.

### Key Objectives

- Establish a professional digital presence for Torok Tours & Travel Ltd
- Create a platform that actively drives business growth
- Serve tourists, corporates, NGOs, and group travel clients
- Reflect the brand's commitment to reliability, comfort, and customer satisfaction

## Tech Stack

- [Next.js](https://nextjs.org/) — React framework with App Router
- [TypeScript](https://www.typescriptlang.org/) — Type-safe JavaScript
- [Tailwind CSS](https://tailwindcss.com/) — Utility-first CSS framework

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
